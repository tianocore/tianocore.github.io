<font color="#0066FF" size="4">
EDK II Projects
</font>
</MTMarkdownOptions>

A modern, feature-rich, cross-platform firmware development environment for the [UEFI](http://uefi.org){:target="_blank"} and PI specifications. Click for a list of [EDK II Documents]({{baseurl}}/docs/EDK_II_Documents.html) and [EDK II Specifications]({{wiki}}/reference/specs-standards/edk_ii_specifications.html)


* [UDK2015]({{baseurl}}/udk/udk2015/ "UEFI Development Kit 2015") is a stable release of portions of our [EDK II]({{baseurl}}/edk2) project.
* [edk2-buildtools]({{wiki}}/build-tooling/build-workflows/edk2_buildtools.html) is the primary set of tools for processing EDK II content.
* [OVMF]({{baseurl}}/ovmf/) is a project to enable UEFI support for Virtual Machines.
* [Shellpkg]({{wiki}}/platforms-packages/core-packages/shell_pkg.html) UEFI Shell is a project to create a UEFI 2.0 Shell implementation.
* [EDK II Application Development Kit (EADK)]({{wiki}}/platforms-packages/core-packages/edkii_eadk.html) includes Standard C Libraries in UEFI Shell Applications (EFI_Toolkit replacement)
* [UEFI Driver Developer Resources with EDK II]({{wiki}}/development/tutorials-howto/driver_developer.html) Support UEFI driver development by independent hardware vendors (IHV), including the UEFI Driver Wizard and UEFI Driver Writers Guide (DWG).
* [Beagle Board]({{wiki}}/platforms-packages/platform-ports/beagle_board_wiki.html) is a low cost highly capable single board computer.
* [edk2-fat-driver]({{wiki}}/platforms-packages/component-guides/edk2_fat_driver.html) is a driver for the FAT12/16/32 filesystems.
* [gcc-shell]({{wiki}}/build-tooling/environment-setup/gcc_shell.html) is a port of the older EFI shell to add GCC build support and ARM processor support.
* [GSOC2011]({{wiki}}/community/events-outreach/gsoc2011.html) is our Google Summer of Code 2011 project
* Some open [Tasks]({{wiki}}/governance/project-management/tasks.html) suggested by our EDK II community
* [Security Package]({{wiki}}/platforms-packages/core-packages/security_pkg.html) EDK II Security Package and other news on Security
* [MinnowBoard]({{wiki}}/platforms-packages/platform-ports/minnow_board.html) open community project with UEFI Developed firmware.
* [MinnowBoardMax]({{wiki}}/platforms-packages/platform-ports/minnow_board_max.html) open community project with UEFI Developed firmware.
* [Coreboot_UEFI_payload]({{wiki}}/platforms-packages/platform-ports/coreboot_uefi_payload.html) open community project for Coreboot Payload Package.
* [EDK II Build Data Viewer](https://github.com/01org/edkiibuilddataviewer){:target="_blank"} open project for EDK II Build Data viewer
